# User Guide – Event Support Desk Prompt Library

## 1. Introduction

This Prompt Library contains five reusable templates designed to help Event Support Desk staff respond to attendee inquiries accurately, politely, and consistently.

The templates help save time, improve communication, and protect personal information.

## 2. Available Templates

### Template 1 – Reply to Attendees
Use this template to answer attendee questions about tickets, badges, schedules, and refunds.

### Template 2 – Calm Message
Use this template to rewrite unclear or impolite messages into professional and respectful responses.

### Template 3 – Mask Details
Use this template to protect personal information by replacing names, emails, and phone numbers with safe codes.

### Template 4 – Bilingual Announcement
Use this template to translate approved event announcements between Arabic and English without changing important information.

### Template 5 – Event Guide Q&A
Use this template to turn five common attendee questions into a clear and organized Q&A guide.

## 3. How to Use the Templates

1. Choose the template that matches your task.
2. Copy the template into ChatGPT.
3. Replace `[INPUT_TEXT]` (or the relevant input variable) with your message or questions.
4. Select the language and tone.
5. Set the maximum word count.
6. Check that the Event Facts are correct.
7. Run the template and review the response before using it.

## 4. Important Guidelines

- Use only approved Event Facts.
- Do not add or guess missing information.
- Never share sensitive personal information.
- Keep responses clear, polite, and professional.
- Check dates, times, and numbers carefully.
- Review AI-generated responses before sending them.
- Refer unanswered questions to the official channel.

## 5. Benefits of the Prompt Library

- Saves staff time.
- Improves response accuracy.
- Supports Arabic and English communication.
- Protects attendee privacy.
- Maintains consistent service quality.
- Makes common tasks easier to complete.

## 6. Final Recommendations

Staff should always select the correct template, provide clear input, and review the generated output.

The Prompt Library is designed to support staff, not replace human review.

Templates should be updated whenever approved Event Facts or service procedures change.
